# Omni Technical Audit & UX Alignment — May 16 2026

## 1. Backend Core Audit: Consolidation & Gaps

### [STRENGTH] Deterministic Logic Over "AI Flakiness"
The `reply_classifier.py` service uses robust, regex-based heuristic matching for reply sentiment. This ensures 100% predictable automation branching for sequences, avoiding the cost and latency of LLM calls for simple categorization.

### [STRENGTH] Statistical Optimization Engine
The `optimization.py` engine implements **Thompson Sampling** for A/B splits. It uses Beta distributions (Alpha/Beta weights) to mathematically optimize lead paths based on reward signals (replies, accepted invites). This is a professional data-science approach to outreach.

### [CRITICAL GAP] Worker Latency & Concurrency
- **Latency**: Real-time inbound events (replies) are processed on a **5-minute polling interval**. This creates a massive delay in sequence advancement.
- **Concurrency**: `max_jobs` is hardcoded to `1`. A single long-running lead generation task will block the entire outreach dispatcher.
- **Reliability**: The Redis Stream consumer lacks a robust retry/dead-letter mechanism for failed event processing.

### [TECHNICAL DEBT] Authentication & Schemas
- **Auth**: Lacks a Refresh Token strategy. Tokens are short-lived and non-revocable.
- **Validation**: No centralized Pydantic schema layer. Data validation is fragmented across routers, increasing the risk of runtime type errors.

## 2. Frontend UX Alignment: The "Real Dashboard" Pivot

### [DIRECTION] Moving Away from "AI Generated" Aesthetics
The UI is pivoting away from "Glassmorphism" and "Gradients" in favor of a clean, high-contrast, data-dense layout inspired by industry standards like **Linear** and **Stripe**.

### [UI REFACTORING TASKS]
- **Solid State**: Remove all `backdrop-blur` and transparency from Sidebars and Topbars.
- **Borders over Shadows**: Use refined border tokens (`border-slate-200/80`) to define sections instead of heavy shadows.
- **Breadcrumb Logic**: Fix the navigation mapping bug where the root path fails to resolve to "Overview".
- **Compactness**: Reduce `PageHeader` vertical padding to maximize "above the fold" data density.
