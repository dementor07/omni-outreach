# 📘 Product Hunt Scraper Automation
### Non-Technical User Guide (Step-by-Step)

This document is written so that **any non-technical team member** can run the Product Hunt automation **from scratch**, without developer help.

---

## 1️⃣ What This Automation Does (In Simple Words)

This automation:
1. Opens Product Hunt automatically
2. Collects:
   - Product details
   - Maker profiles
   - Social links
3. Filters and enriches the data
4. Converts it into **lead-ready format**
5. Pushes the final result to **Google Sheets**

✅ **Final Result:**  
A Google Sheet containing **clean, filtered, enriched leads** ready for outreach.

## 3️⃣ System Requirements

### Required
- Windows 10 / Windows 11
- Google Chrome browser
- Internet connection

### Not Required
- Coding knowledge
- GitHub knowledge
- Python experience

---

## 4️⃣ Step 1 – Install Python (One-Time Setup)

1. Open browser
2. Go to: https://www.python.org/downloads/
3. Download **Python 3.10 or newer**
4. During installation:
   ✅ **CHECK** → `Add Python to PATH`
5. Click **Install**
6. Restart your computer

---

## 5️⃣ Step 2 – Extract the Zip File

1. Right-click the zip file
2. Click **Extract All**
3. Open the extracted folder  
   Example:
   ```
   D:\ProductHuntAutomation\
   ```

---

## 6️⃣ Step 3 – Open Command Prompt (No Coding)

1. Open the extracted folder
2. Click the **address bar**
3. Type `cmd`
4. Press **Enter**

A black Command Prompt window will open **inside the folder**.

---

## 7️⃣ Step 4 – Install Required Libraries (One Command)

Run this command **once**:

```bash
pip install -r requirements.txt
```

Wait until installation finishes.

## 🔟 Step 6 – Run the Automation (Main Step)

Run this command:

```bash
python producthunt_scraper.py
```

### What You Will See:
- Chrome opens automatically
- Pages scroll and load
- Data collection happens
- CSV files are created
- Data is pushed to Google Sheets

⏳ Typical runtime: **5–15 minutes**

✅ You may **MINIMIZE** Chrome  
❌ Do **NOT CLOSE** Chrome while automation is running

## 1️⃣2️⃣ Common Issues & Fixes

### ❌ “Python is not recognized”
✔️ Reinstall Python  
✔️ Ensure **Add Python to PATH** is checked

---

### ❌ Chrome opens and closes immediately
✔️ Check internet connection  
✔️ Do not touch the system during run

---

### ❌ Google Sheet not updating
✔️ Check `.env` file  
✔️ Ensure Google Sheet is shared with service account

---
